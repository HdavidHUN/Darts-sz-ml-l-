# Darts-sz-ml-l-
Egy egy kifejezetten olyan dartsosoknak készült program akiknek nincs lehetőség vagy nem akarnak nagy összeget költeni különböző darts számlálókra viszont akarnak egy korrek jól működő pontos számlálót ami egy okos telefon vagy tablet kameráját használja kifejezetten hobbi játékosoknak készült baráti meccsekre
